# Day 4 — Python

Practising randomisation and Python modules through small programs and a Rock Paper Scissors game.

### Programs
- `my_module.py` — Creating and importing a custom Python module.
- `random_number.py` — Generating random numbers using the random module.
- `rock_paper_scissors.py` — Rock Paper Scissors game using random choices.

### Concepts
- Python modules and imports
- `random` module
- `random.randint()`
- `random.random()`
- Lists and indexing
- Random number generation
- Rock Paper Scissors game logic
