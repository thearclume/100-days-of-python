# Day 01 — Band Name Generator

## Project Overview

A simple Python program that generates a band name using information provided by the user.

## Concepts Learned

- Printing output using `print()`
- Taking user input using `input()`
- Storing values in variables
- Combining strings
- Basic program execution

## How It Works

1. The program asks the user for their city.
2. It asks for the name of their pet.
3. It combines both inputs to generate a band name.

## Example

```text
Welcome to the Band Name Generator.
What's the name of the city you grew up in?
Hyderabad
What's your pet's name?
Bruno

Your band name could be Hyderabad Bruno
```

This project introduced me to the basic flow of a Python program: taking input, storing data, and producing output.
