# Day 6 — Python

Practising Python functions, indentation, and loops through coding challenges. Learning to control program flow using `while` loops and solving obstacle-based challenges, including escaping a maze.

### Programs
- `functions.py` — Defining and calling Python functions.
- `hurdles_loop.py` — Solving the Hurdles Loop Challenge.
- `while_loop.py` — Practising while loops.
- `hurdles_while.py` — Jumping over hurdles using while loops.
- `variable_height_hurdles.py` — Handling hurdles with variable heights.
- `maze.py` — Final project: Escaping the Maze.

### Concepts
- Python functions
- Defining and calling functions
- Code indentation
- `while` loops
- Loop conditions
- Repeating actions
- Conditional statements
- Variable-height obstacles
- Problem-solving and logic
