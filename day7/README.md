# Day 7 — Python

Building a Hangman game using Python. Practising problem-solving, loops, conditions, and lists by developing the game step by step. Implementing random word selection, letter checking, hidden word display, and a lives system.

### Programs
- `step1.py` — Selecting a random word and checking guesses.
- `step2.py` — Replacing blanks with correctly guessed letters.
- `step3.py` — Checking whether the player has won.
- `step4.py` — Tracking the player's remaining lives.
- `step5.py` — Improving the game with input validation and repeated-guess detection.
- `hangman.py` — Complete Hangman game.

### Concepts
- Breaking complex problems into flowcharts
- Python `random` module
- `random.choice()`
- `while` loops
- `for` loops
- Lists and list operations
- Conditional statements
- String methods
- Input validation
- Tracking lives and guessed letters
- Win and lose conditions
- Problem-solving and debugging
